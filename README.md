# Сложно сосредоточиться

Адаптивная страница о концентрации внимания. В проекте реализованы светлая и тёмная темы, переключение темы, адаптивная вёрстка и галерея изображений.

Откройте `index.html` в браузере, чтобы посмотреть страницу.


Репозиторий проекта: https://github.com/xyzxyzm/slozhno-sosredotochitsya-ad
